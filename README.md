# 🖨️ Bumble Printers – E-Commerce Website  

## 📌 Project Overview  
Bumble Printers is a fully functional e-commerce website built as part of the **Information Systems coursework (60% weightage)**. The project demonstrates the use of **HTML5, CSS3, and JavaScript** to design and develop a responsive and user-friendly platform for browsing and purchasing printers.  

The goal of this project is to provide a **simple yet elegant shopping experience**, featuring multiple pages such as **Homepage, Products, Blog, Research, About Us, and Contact**.  

---

## 🚀 Features  
- **Responsive design** using HTML5, CSS3, and JavaScript  
- **Homepage** with navigation, banners, new arrivals, seasonal offers, and footer  
- **Products Page** showcasing multiple printers with descriptions, pricing, discounts, and hover effects  
- **Blog Page** covering technology’s impact on daily life and businesses  
- **Research Page** explaining design inspirations and implementation choices  
- **About Us Page** with team portfolios, skills, education, and contributions  
- **Contact Page** with a **form validation system** (JavaScript checks for empty fields, phone number validation, and gender selection)  
- **Testing** documentation for form submissions, hover effects, and link redirections  

---

## 🛠️ Tools & Technologies  
- **HTML5** → Website structure  
- **CSS3** → Styling, layout, responsiveness, hover effects  
- **JavaScript** → Form validation, interactivity  
- **VS Code** → Development environment  
- **Balsamiq** → Wireframing  
- **Snipping Tool** → Testing screenshots
